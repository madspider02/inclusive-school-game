# 新手老師大作戰 v5.1.6 Final Reflection Flow

本版流程已固定為：

第 8 個情境完成 → 💭 我的重新思考（10–500 字） → 「完成遊戲，查看我的教師樣貌」 → 自動提交 Google Sheet → DAY 1 COMPLETE → 教師樣貌／雷達／成長紀錄／成長卡。

- 不會在反思前顯示 DAY 1 COMPLETE。
- 反思頁不顯示 RESEARCH MODE／完成本次研究紀錄說明卡。
- 反思最低 10 字、最多 500 字。
- 資料成功送出後才顯示教師樣貌結果。
- GitHub 更新時請直接覆蓋 `index.html` 與 `game.js`。
